# Support

## How to get help

### Documentation

The HASTE documentation covers architecture, API reference, deployment, and local development:

- **[Online docs](https://microsoft.github.io/haste)** — Jupyter Book site built from [`docs/`](docs/)
- **[README](README.md)** — Local development setup and project overview
- **[CONTRIBUTING](CONTRIBUTING.md)** — How to contribute code or docs

### GitHub Issues

Use [GitHub Issues](../../issues) to report bugs or request features. Before opening a new issue:

1. Search [existing issues](../../issues) (open and closed) to avoid duplicates.
2. Check the [FAQ in the documentation](https://microsoft.github.io/haste) for known solutions.
3. Use the appropriate issue template — bug report or feature request.

### GitHub Discussions

Use [GitHub Discussions](../../discussions) for questions, ideas, and general conversation about HASTE. This is the right place for:

- "How do I...?" questions
- Sharing use cases or results
- Proposing new directions before opening a feature request

### Security vulnerabilities

**Do not** report security issues in public GitHub Issues. See [SECURITY.md](SECURITY.md) for the responsible disclosure process.

## Microsoft support policy

HASTE is an open-source project maintained on a best-effort basis. It is **not** covered by any Microsoft support plans or SLAs. Community contributions are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).
